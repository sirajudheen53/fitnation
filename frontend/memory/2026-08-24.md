**Status:** Complete ✅

**Verification:**
- `npx tsc --noEmit` → 0 errors ✅

- `npx next build` → all 6 diet routes build ✅

- Backend customer serializer returns `name` (not first_name/last_name); used existing `getCustomerDisplayName` helper for display.
- Backend API shape confirmed from `backend/apps/diet/` (serializers/views/models).
